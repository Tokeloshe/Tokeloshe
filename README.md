## What I build

| Project | What it is | |
|---|---|---|
| **[VUURWERK](https://github.com/Tokeloshe/vuurwerk-firmware)** | Firmware that turns a Quansheng UV-K5 into a radio that hunts for voices by itself. Flashed by hundreds of operators. | [![release](https://img.shields.io/github/v/release/Tokeloshe/vuurwerk-firmware?label=)](https://github.com/Tokeloshe/vuurwerk-firmware/releases/latest) |
| **[Tomo](https://github.com/Tokeloshe/tomo)** | A quiet social reading companion for Kobo and Kindle e-readers, with handwritten pen pal letters. | [![release](https://img.shields.io/github/v/release/Tokeloshe/tomo?sort=semver&label=)](https://github.com/Tokeloshe/tomo/releases/latest) |
| **[WatchlistBox](https://github.com/Tokeloshe/WatchlistBoxApp)** | Turns a Windows PC or a Mac into the box under your television. | [![release](https://img.shields.io/github/v/release/Tokeloshe/WatchlistBoxApp?label=)](https://github.com/Tokeloshe/WatchlistBoxApp/releases/latest) |
| **[Starboard](https://github.com/Tokeloshe/starboard-protocol)** | An open, deterministic give-way protocol, so two satellites that cannot talk to each other still agree on which one moves. | |

All of it is free to use. No ads, no tracking.

## How I work

- One person, evenings and weekends, real hardware on the bench.
- Releases are tested before they ship, and the docs describe what the thing actually does.
- Bug reports get answers. Sponsors' reports get them first.
